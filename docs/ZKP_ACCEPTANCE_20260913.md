## 可重复执行

在作者机器构造符合 v2 协议的 witness（见 [执行协议](EXECUTION_TRUST.md)），并先通过现有行情流程登记数据。然后在项目根目录运行：

```bash
backend/.venv/bin/python scripts/prove-private-program.py \
  --witness /absolute/author/input.private.json \
  --output /absolute/author/new-proof-directory \
  --publish-local
```

输出目录必须不存在。`--publish-local` 向本机项目数据库发布公开身份、证明与结果，不上传私有 witness。省略该参数只生成和验证证明。如真实证明已经生成但尚未发布，可在同一命令附加 `--resume`：使用保存的 witness、身份和 receipt，仍完整重新验证，不重新证明。已发布的 receipt 不允许重复发布。

ZKP 对验证者隐藏 witness；若在普通平台主机生成证明，该主机仍能读取 witness。作者关机后持续保密运行和生成证明，需要在合格 TEE 内执行/证明，或另行实现真实的保密计算协议。公开收益与用户可见订单也可能泄漏策略行为，TEE 无法消除这些输出带来的推断。
