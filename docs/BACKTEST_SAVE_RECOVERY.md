# 回测报告保存遇到502后的恢复

2026-11-13排查截图中的中芯国际688981.SS、5分钟、完整HF历史。

原始短暂502没有持续重现：API及Vite代理健康检查均为200；使用生产TypeScript回测代码计算70,570根bar、1,401笔成交，11,723,018字节报告经5173端口的实际代理连续两次保存201、历史重读200。不能据此断言最初502的底层原因已经确定。

确定复现的应用缺陷是：浏览器Worker已经计算完成并写入本地缓存，但`/compute/runs`保存请求一旦返回502，`savedResult`异常会将整个任务标为失败，导致页面不展示已完成的净值和成交。回归命令 `cd frontend && npx vitest run src/tests/client.test.ts` 在修复前直接报“服务请求失败（HTTP 502）”。

修复后的行为：

- 仅在保存报告发生网络中断、超时、502/503/504时保留已完成结果；401/403/422、计算异常、取消和退出仍正常阻止返回结果。
- 完整净值及成交保存在当前账号的IndexedDB，K线按原不可变dataset_id重建；结果和历史明确标注“仅此浏览器、尚未同步”。
- 回测历史可以重开、删除本地记录，或手动“重试同步”。同步上传已有报告，不重新计算策略，不自动重试POST请求。
- 已有会话在临时网关错误时沿用本地身份缓存；首次未认证会话及明确认证错误不使用缓存。退出时原有取消和账户隔离规则继续生效。
- 小型历史索引与完整曲线分开读取，原子更新索引；同步成功清理临时副本。无需迁移数据库版本。

真实浏览器验收入口（仅Vite开发环境）：`/tests/fixtures/save-recovery.html`。它创建独立诊断会话，在第一次真实保存调用处注入HTTP 502，执行生产浏览器回测和结果组件；之后通过真实API同步并重读。验收显示70,570个完整资金观察点、1,401笔成交，且策略只执行一次。该页面不会执行交易或上链操作。

修复后534项Vitest测试、63项journal测试、TypeScript检查、相关ESLint及生产构建通过；退出、权限拒绝、不同账号隔离和不重新计算的同步均有回归覆盖。
