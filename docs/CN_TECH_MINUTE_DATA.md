# 半导体、机器人与航天 A 股分钟数据

## Hugging Face 长历史：图表与三个回测框架

[上游数据集](https://huggingface.co/datasets/neigezhu/china-a-share-1min-ohlcv) 固定版本 `ba589a11534825044fe5a6b84838f50ba8d8d188`，Apache-2.0。已为项目全部 **35只沪深A股**发布1分、5分、15分、1小时、4小时、日线、周线，共245份独立行情；不覆盖美股、港股或ETF。原始Parquet共28,116,639条观察记录；09:30开盘观察并入首根分钟后为27,999,945根1分钟K线，保留全部成交量。各股起始时间取决于上市和上游实际覆盖。

使用：选A股会默认进入明确标注的Hugging Face来源；也可从顶部“行情数据源”选择“A股历史与回测（Hugging Face）”。价格口径为不复权，选择任意已发布周期即可看图。Atlas、vn.py、RQAlpha均可选择这一来源进行研究回测；原生两个框架当前仅适配内置SMA；网页空日期使用完整发布范围，直接API必须指定日期，单次不超过100万根。历史快照末日是2026-08-07，当天仅到北京时间10:21；日线/4小时仅发布截至08-06的完整交易日，周线只保留交易日历完整覆盖的周。不自动拼接新浪近期窗口，也不会将该快照展示为实时行情。

规范化版本 `hf-session-open-v3`：上游标签09:30、09:31–11:30、13:01–15:00；09:30观察并入首个完成分钟，统一发布UTC开盘标签（北京时间09:30–11:29、13:00–14:59）。5/15/60分钟仅从完整分钟组聚合，不跨午休、不填造缺失组。4小时对应完整交易日四个交易小时，与本源日线OHLCV一致。周线依上游交易日历聚合，缺交易日或末周不完整时不发布。成交量单位为股；零成交分钟保留，三个框架均不在零成交K线上成交。每块最多2000根并有SHA256校验，坏缓存重取同一哈希的分块，浏览器缓存空间不足时仍可读取已校验的网络行情。

原始行情不复权，不含公司行动，且上游不披露底层提供方。与其他来源日线存在差异仍记录在原有 `daily-reconciliation.json` 中；开放研究回测不代表差异已经消除或经交易所独立核验。RQAlpha以本地bundle补充股票资料、公司行动、交易日历与涨跌停参考字段，使用原生账户。可选统一研究口径使三者共享成交规则，详情见回测框架说明；原生模式下Atlas/vn.py沿用现有通用研究账户，三框架的撮合时点、费用、T+1和公司行动处理不同，不承诺收益相同或全部具备完整实盘交易规则。

本机完整分块验收和735组真实回放（35股×7周期×3框架，每组最近128根）全部通过。每组验证相同OHLCV、逐根账户记录、有限正净值、不在零成交bar成交、现金/持仓非负。报告在 `backend/.data/cn-tech/huggingface/metadata/three-engine-acceptance.json`，含dataset_id、输入SHA256、框架版本及结果。此验收是固定窗口的接入验收，不代表已经对所有历史区间或所有策略完成检验。

复跑（从backend目录）：

```bash
.venv/bin/python -m app.data.import_huggingface_cn_minutes
.venv/bin/python -m app.data.verify_huggingface_engines --full-integrity
# 中断后仅重跑失败或未完成项
.venv/bin/python -m app.data.verify_huggingface_engines --full-integrity --resume
```

可用 `--symbols 300750.SZ 688981.SS` 限定股票。原始Parquet、固定版本覆盖清单、日历、逐文件SHA256和导入报告均保存在上述本机忽略目录，不上传或改写其他来源。详细边界见[回测框架说明](BACKTEST_ENGINES.md)。

## 网页使用

刷新 http://127.0.0.1:5173 ，在市场搜索框输入“半导体”“机器人”“航天”或具体代码/名称。选择股票后，1分和5分按钮已经开放，另可切换15分、1时和日线。行情来源选自动，价格口径选择自动或不复权。默认标的列表请求100项，包含新增股票。

分钟回测使用“当前引擎”，可以选择模板和数据实际覆盖的日期。当前通用引擎尚未完整模拟A股T+1、整手、涨跌停等规则，页面结果会提示。年化因子按A股每天240分钟、每年252个交易日估算。自动来源下RQAlpha仍使用原生bundle日线；选择Hugging Face时三框架均支持上述已发布周期，见 [可选引擎](BACKTEST_ENGINES.md)。

## 本地保存与复用

- backend/.data/cn-tech/时间目录/股票代码/*.source.json：上游原始响应。
- 同目录 *.csv.gz：规范化OHLCV，UTC开盘时间。
- 同目录 report.json：每只股票的周期、数量、起止时间、原始SHA256及不可变dataset_id。
- backend/.data/cn-tech/latest.json：最新导入报告位置和成功/失败数量。
- backend/.data/cache/market.sqlite3：本地缓存；分钟时间语义使用bar-open-v1版本键防止与旧收盘标签混合。
- backend/.data/objects/public 和 atlas_quant.db：图表及浏览器回测可读取的不可变行情分块和清单。

更新命令（独立采集与发布，不在回测请求中临时抓取）：

```bash
cd backend
# 默认更新项目目录的全部沪深股票的1分、5分、15分、1小时快照
.venv/bin/python -m app.data.import_cn_tech
# 也可仅更新部分已收录标的和周期
.venv/bin/python -m app.data.import_cn_tech --symbols 688981.SS 300124.SZ --intervals 1m 5m
```

本地数据受Git忽略规则保护，不随源码提交自动上传。每次执行按股票、周期保存进度；失败保留原发布版本，并在报告中记录失败，不会替换为演示数据。
