# 工作空间重构与验收记录

日期：2026-09-06。范围：QuantJudge 分支的前端信息架构、视觉系统和交互可靠性。

## 这次解决什么

原界面将全局导航、项目阶段、工具状态和编辑表单同时堆在顶部，重点不明确；不同页面的字号、间距与表单密度也不一致。本次把它们分成三个层级：全局工作模式、当前研究上下文、当前任务内容。

| 工作模式 | 主要任务 | 新版变化 |
| --- | --- | --- |
| 行情与回测 | 单标的行情、指标、回测、基本面 | 统一图表工具和参数面板密度；修正侧栏加入后拖动宽度的计算范围 |
| 投资组合 | 配置资产、权重、再平衡和风险约束 | 统一成分表、参数栏和资产选择器样式；窄屏上下排列 |
| 策略实验室 | 构建、编排、验证、归档、证明 | 新增项目总览和两条明确入口；每个阶段解释目的、下一步和能力边界 |
| 策略市场 | 比较业绩与证据、查看订阅 | 收益、风险、评分、证据分层；演示 / 非演示 / ZKP 筛选；更清晰的详情面板 |

## 导航与视觉

- 桌面使用可收起的左侧导航，手机使用常驻底部导航。
- 四个工作模式支持地址 hash、刷新恢复和浏览器前进 / 后退。
- 顶栏只保留当前上下文及行情、回测等工具，取消重复的模式导航。
- 蓝灰底色、浅蓝主操作、青 / 红金融数据；统一字号、边框、圆角、间距和焦点状态。
- 单独的 `frontend/src/workspace.css` 集中工作空间设计规则；仍保留原有图表与复杂控件样式，并非已经清除了全部旧 CSS。
- 提供跳过导航入口、稳定的导航可访问名称、减少动画偏好支持。

## 策略实验室

默认进入项目总览，不再直接落入复杂工作流。用户先选择“可视化构建”或“导入策略包”，再进入规则、AI 工作流、研究验证、版本包和 ZKP 证明。

总览展示当前项目、假设、标的、周期、已通过的后端门禁和待完成要求。门禁仍由后端计算，不允许前端手工勾选。编辑器按访问需要加载，进入总览不会立刻加载所有开发工具。

规则表单为观察指标、条件、比较对象和阈值增加可见标签；手机布局改为自适应双列。工作流使用低对比网点背景、更清晰的选中状态及模板 / 画布 / 配置三级布局。

## 修复的交互与信息问题

1. 关闭的抽屉仍覆盖阴影、且内部控件可能进入键盘焦点序列：关闭时隐藏整个抽屉层。
2. 项目选择栏实际有四个元素却只分配三列，编辑按钮换行：修正列定义。
3. 市场列表的图标和徽章挤压策略名称：重排名称、开发者及证据徽章，允许合理换行。
4. 切换策略后，旧验证请求晚返回可能串到新详情：请求序号隔离过期响应，验证期间禁止重复点击。
5. 旧的链上确认状态覆盖最新失败状态：优先使用当前验证结果。
6. 无报告被展示为 0% 收益：缺失指标显示“—”，评分显示“待评测”。
7. 仅有签名被当作已经验证：先显示“业绩证据待验证”，主动验算通过后才展示已复核。
8. 发布和订阅弹窗：焦点约束在弹窗内，Esc 关闭后回到原操作入口。

- `cd frontend && pnpm test`：6 个测试文件、17 项测试通过。
- 新增 5 项市场回归测试：未验证签名、过期验证响应、最新链状态优先、筛选 / 缺失数据、弹窗键盘焦点（部分场景合并在同一测试中）。
- 浏览器截图检查：1600×1000 的实验室、工作流、市场、组合及行情界面；390×844 的实验室、规则构建、市场及资产选择器。
- 1280×900 检查页面宽度、模式切换、返回和刷新恢复；已检查的组合与市场页面无整页横向溢出。
- 本地截图位于 `output/playwright/`，不提交 Git。

## 明确没有改变的能力边界

本次没有修改后端评测算法、策略执行引擎、密码学协议、数据库或 Supervisor，也没有创建真实订阅、交易或上链记录。

UI 中的“结构校验通过”不表示 AI 工作流已经运行；上传与加密保存 Python 策略包不等于已有通用隔离执行服务；平台 Ed25519 签名不等于 ZKP；固定 SMA 证明不等于支持任意策略与 TEE。上述边界已在实验室总览、相关阶段及证据详情中明确展示。

本轮验收覆盖前端构建、回归测试与浏览器交互，不代表完成全链路生产认证。真实支付、任意策略执行、AI 推理、TEE 和更广的 ZKP 覆盖仍需各自独立的实现与验收。
