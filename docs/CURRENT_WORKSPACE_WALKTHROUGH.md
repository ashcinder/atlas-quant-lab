# 当前工作流与AI使用

更新：2026-10-29；按QuantJudge `672e8b8` 核对。新安装从空账号/空工作区开始，下列步骤使用你实际创建的版本和实例ID，不依赖过去的验收记录。安装见 [README](../README.md#本地启动)。

## 1. 创建策略与版本

1. 注册并登录，进入策略实验室，选择模板、图形或代码开发方式。
2. 代码方式选择“载入持续运行模板”，只使用 `target_bps(index, close, sma)` 的受限Python；先检查代码，再手动回测。其他编辑语言和任意Python导入并不自动支持执行。
3. 保存当前确定性快照为不可变运行版本，记录界面返回的真实版本ID。修改草稿不会修改已保存版本。
4. 自己使用自己版本不额外付款。向其他用户开放时，先公开版本并设置BKC报价；新用户需在同一持久链完成付款授权，不能沿用旧免费订阅教程。

普通回测、运行版本保存和公开都不会自动生成Proof。发布隐私与收费规则见 [策略开发](STRATEGY_DEVELOPMENT.md) 和 [BKC工作流](TRINE_SERVICE_WORKFLOW.md)。

## 2. 先做平台模拟

进入策略交易/策略运行，选择刚创建的版本、支持的市场、单标的及计价币种，分配资金并启动平台模拟。行情失败、过期或缺失时查看错误，不使用演示价格伪造正常资产。

检查实例的信号、持仓、成交和净值，再到资产概览与自动交易账本追溯同一实例。模拟资金与真实交易所资产、手工账本分别展示；暂停/停止不自动清仓，也不补造离线成交。

平台模拟需要后端持续运行；浏览器关闭不等于后台停止，机器休眠或后端关闭则不能继续获取行情。A股目录与平台模拟不等于券商实盘，完整成交规则仍有限制，见 [交易指南](TRADING.md)。

## 3. 按需接交易所测试账户

先在对应交易所创建测试账户，再在交易账户页面配置自己的Binance/OKX模拟凭据并验证连接；“已配置”不等于连接成功。只有明确选择 `exchange_test` 和实例 `demo_auto=true` 才自动尝试测试网订单。未知结果应先查询和对账，不重复提交。

实盘路径默认关闭，只允许绑定所有者逐笔预览并确认，不能把测试网自动执行解释为自动实盘。完整变量、订单和异常规则见 [交易账户接入](TRADING.md)。

## 4. AI辅助与Proof

- 本地设置的AI服务需要提供方、模型、凭据和发送授权；未配置或调用失败不能标成真实AI验收。
- 代码助手可接收当前代码与问题，生成后先审阅再应用。模板/图形回测可配置六阶段AI审核，确定性风控仍生效；持续运行版本不自动执行这些AI节点。
- 普通云AI会经手代码和问题，不承诺管理员不可读；真实TEE及外部AI计算证明仍未完成。
- 如需真实受限程序Proof，另按 [代码到Proof指南](CODE_TO_PROOF_WALKTHROUGH.md) 构建工具、登记数据、生成receipt并核验，不把一次普通回测当作Proof。
