# ZKP / zkVM 集成与真实验收（2026-09-16）

## 新增功能

- 策略市场 → Proof → 独立验证页面：展示程序 ID、receipt 与公开输入哈希、收益 Journal、证明文件下载和固定 GitHub 源码链接。
- `POST /api/v1/quantjudge/zk-proofs/{id}/verify` 重新读取真实 receipt，检查文件哈希、固定登记 image、身份与完整 journal，返回实际验证耗时。每个应用进程最多同时执行两次此接口验证。登记状态本身不产生验证通过标记。
- 作者侧自动准备工具：从下载的 market.json 和受支持 Python 子集生成私有 witness、随机 salt/nonce 并执行固定 guest 预检。私有输入没有新增 HTTP 上传入口。
- 修复再次验证时只使用数据库 image ID 的缺口，现需重新核对不可变的程序登记。

## 一条命令重新验收

输出目录必须不存在。在项目根运行：

```bash
backend/.venv/bin/python scripts/zkp-e2e.py --output /absolute/new-acceptance-directory
```

真正生成新的 RISC Zero receipt，然后独立验证，检查损坏/错误 image/重放，使用临时数据库发布报告，并调用真实 HTTP 验证接口。测试使用明确标记的合成行情；不修改生产数据库或链。receipt 是密码学证据，验收 JSON 本身不是证明。

## 作者工作流

在工作室登记市场数据并下载为 market.json。受支持源码示例：`strategy/examples/zk-python/strategy.py`。

```bash
backend/.venv/bin/python scripts/prepare-zk-witness.py \
  --dataset /absolute/market.json \
  --python-source strategy/examples/zk-python/strategy.py \
  --output /absolute/new-witness.private.json \
  --proof-output /absolute/new-proof-directory \
  --publish-local
```

该命令在作者设备准备输入、生成并验证证明。`--publish-local` 使用本地项目已登记数据集，创建策略身份并发布公开报告；不上传私有 witness。省略此参数即可仅证明。远程平台使用现有开发者凭证和 receipt 上传接口：先根据预检承诺创建身份，再仅修改本地 witness 的 agent_id，保持 salt/program 不变，然后证明并上传。

生成 receipt 为 RISC Zero bincode 二进制 `.r0`；公开 Journal 为 JSON，收益 ppm、Sharpe milli、资金 micros 均使用整数编码。Groth16 导出是公开的 imageId、journal、seal JSON，由独立 exporter 从已验证 receipt 转换。

## 必须区分的未覆盖范围

此处证明固定 v2 有界整数程序在承诺数据上的执行及其扣费收益。`target_bps(index, close, sma)` 的受限 Python 被编译为该程序；证明不覆盖 CPython 或编译器正确性，也不自动覆盖现有浮点回测引擎的每一个模板、图形指标或任意 Python/AI 策略。

数据 hash 证明使用了哪份数据，不证明数据由交易所签名；zkTLS、实盘成交完整性、任意外部 AI 推理与管理员不可读托管均未实现。实际部署的原 Supervisor 与隔离链不同，本轮未把隔离链证明伪装成原 Supervisor 的确认。现有 Supervisor 验收与限制见 contracts/README.md。

因此本轮是真实跑通受支持协议的生成、发布、验证及隔离合约验收，不能宣称所有语言、模板、实盘及生产部署已经一次完成。

## 继续集成：指定区间与离线验证包

- 工作室 ZKP 页面可选择 UTC 开始/结束日期，结束日期为排他边界。API 支持带时区的 `start` / `end`；拒绝逆序或无时区输入，只登记区间内已经收盘的 K 线。切换标的、周期或日期后，旧数据集不能继续用于当前发布操作。
- Proof 页面可下载 ZIP 验证包。私有策略仅导出 receipt、journal、历史数据及验证脚本；显式公开样本另带源码与 public witness，不读取作者私有文件。
- 在自己的可信仓库构建验证器后运行：

```bash
backend/.venv/bin/python scripts/verify-proof-bundle.py \
  --bundle /absolute/extracted-bundle --repository /absolute/atlas-repository \
  --expected-agent qja_3c423f6e38fe444f \
  --expected-return-ppm 17269
```

验证器固定 ID 从可信仓库读取，不信任下载包自行声明的 ID。收益 ppm 是百万分之一；上述 17269 表示 1.7269%。完整验证无网络请求、无数据库写入。公开源码经受限编译器编译后重放，对照真实 receipt 的完整 journal；源码绝不作为 Python 执行。
