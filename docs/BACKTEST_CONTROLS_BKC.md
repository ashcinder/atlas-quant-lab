# 回测控件、指标与 BKC 接入

## 使用

- 行情与回测 → 策略参数 → 回测时间：选择本地开始/结束时间，或 30/90/180 天、1 年预设。提交时转换为 UTC；留空沿用数据源默认范围。资金、手续费、滑点、价差、仓位、成交量参与率、止损止盈沿用回测引擎参数。
- 图表 → 指标：选择 MA、EMA、BOLL、VWAP、成交量、MACD、RSI、KDJ、ATR、CCI、ROC、OBV。可调指标周期和颜色，设置按本地登录用户保存。指标仅控制图表显示，不改变策略交易规则。VWAP 按 UTC 日重置。
- 顶部 MetaMask：连接 Supervisor 网络，检查链 ID 和创世区块并显示余额。
- 策略市场 → 我的策略：可以固定当前版本的 BKC 价格和钱包收款地址。买方在策略卡片查看价格、确认订单后由 MetaMask 签名付款，后台核验交易后授予当前版本使用权。无自动续费，新版本需单独订阅；既有订阅保留。
- 回测结果 → 公开回测收益并上链：预览公开内容后，由 MetaMask 发送零金额自转账，交易 calldata 包含指标、配置与完整请求/报告 SHA-256 摘要。保留交易哈希，可使用“核验交易 / 恢复订单”检查结果。

## 运行配置

后端重启后加载新路由与 SQLite 表，前端使用原有启动/构建流程。

- `QUANTJUDGE_SUPERVISOR_RPC_URL`：后端访问的 Supervisor RPC（沿用现有客户端配置）。
- `ATLAS_WALLET_RPC_URL`：MetaMask 可访问的 RPC；未设置则使用后端客户端的 RPC 地址。远程服务与本机钱包使用不同网络地址时应显式配置，两端必须指向同一条链。
- 链 ID 为 1051，原生币 BKC。浏览器需要安装 MetaMask；已有同 ID 网络必须与后端创世区块一致。

## 范围与限制

ZKP、zkVM、现有 Proof 页面及验证合约未修改。报告上链证明的是某个内容被记录，不能证明策略执行或收益正确。单机 Supervisor 的记录公开程度与持久性取决于节点部署、访问和备份；不能据此宣称独立公共网络共识保证。

订阅采用原生 BKC 转账与后台授权数据库，没有新增托管/自动续费智能合约。确认时检查发送方、收款人、金额、订单数据、交易哈希、成功回执与规范区块；尚未实现持续重组监控或失败付款订单重建。保留钱包交易哈希，不要在确认状态未知时重复付款。

## 验证

后端 50 项测试覆盖订阅付费门禁、价格固定、重复确认、错链/金额/钱包/内容、待确认与失败交易、规范区块、报告私有字段排除及既有回测/订阅逻辑。前端 13 项测试覆盖时间参数、指标数值与因果性、钱包身份检查、结果面板和订阅界面。另执行 TypeScript 检查、生产构建和新增逻辑 ESLint 检查。

桌面/窄屏视觉检查使用隔离的模拟行情预览。尚未使用用户钱包实际付款，尚未部署至远程站点。
