# 重构进度与验证边界

更新：2026-09-07。此前 UI 检查点已推送 GitHub `QuantJudge` 分支，提交 `55e3980`。

## 本轮交付

### 连贯的操作流程

- 实验室与组合配置首次访问后保留在内存；切换主导航不会丢失编辑状态，不把源码、提示词和凭证写入 localStorage。
- 规则 / 工作流替换前确认；编辑中保存不会把后来修改误标为已保存。
- 切换 Agent 清空旧凭证、包绑定、证明与数据集；迟到的请求不能恢复旧会话资料。
- 项目请求更新来源项目，不因晚返回而跳回之前的项目。
- 组件错误隔离在当前工作区，并提供重载入口。

### 状态与展示

- 顶部新增“系统状态”，区分后端在线、证明验证器就绪、链连接和尚未接入的能力。
- 启动部分失败不再阻断所有目录，提供重新连接入口；网络、超时、Pydantic 校验错误均有可读提示。
- 请求没有自动写入重试；超时提示后台任务可能仍在运行，避免重复提交。
- 切换标的 / 周期清除旧图表和交易结果，迟到回测不会覆盖新标的。
- 交易表使用结果的实际计价币种并保留分钟时间；风险指标采用中文说明，组合增加相关性矩阵，未定义值显示“—”。

### 后端正确性

- 内置策略参数统一校验；DCA 间隔为零等非法输入返回 422。
- 修复 MACD 周期关系与马丁 RSI 入场参数未真正生效的问题。
- 组合先完成卖出再按资金比例买入，消除成分排列顺序导致的调仓偏差。
- 校验重复标的、有限数值和日期；规范化组合代码，避免显式权重匹配失败。
- 常量序列相关性使用 null；结果明确记录 valuation_currency，不改变原有会计计算。
- 后端测试的数据库、缓存、证明与密钥均隔离到临时目录。

### 私有部署基础

新增非 root 容器、只读根文件系统、单 worker、回环监听、持久化数据卷、同源代理、健康检查、依赖版本固定、CI 与可重复的容器冒烟测试。详见 [部署指南](DEPLOYMENT.md)。没有启动或修改 Supervisor，没有进行真实交易、收费或对外部署。
