# 参数穷举

入口：策略实验室的模板、图形化、参数研究，以及行情页的策略参数侧栏。

展开“参数穷举”，选择历史开始/结束时间，勾选数值参数并填写起点、终点、步长。起点到终点按步长穷举，未勾选参数固定；支持最多 100 个组合。整数参数不接受小数。各组合复用现有 `/api/v1/backtests` 与当前页面的资金、费用、仓位设置；批量搜索不启用 AI 执行流程，不保存回测历史。

按总收益率降序显示，附带最大回撤、Sharpe、参数值和失败原因。首行仅是本次成功组合中的最佳结果。应用参数会回填模板、图形化草稿或行情参数；参数研究页将胜出值填入研究网格，供后续稳健性验证。保存策略和独立回测仍由用户操作。搜索时间区间与参数回填是独立的，单独回测时请设置一致时间。

搜索在当前浏览器页面串行提交，关闭/切换组件或点击停止后不再提交新组合；已经到达服务器的当前回测可能继续完成。结果仅保留在当前组件，刷新页面会清除。运行开始固定策略快照；草稿或配置变化后禁止将旧结果应用回新草稿。返回的行情序列与首个有效组合不一致时，该组合不参加排名。

历史搜索最优不是未来收益保证；可使用原有参数研究的留出集和滚动验证继续检查。当前只穷举数值参数，不搜索代码、布尔开关或枚举策略类型。ZKP/zkVM 未修改。

验证：参数范围边界、组合上限、图形化嵌套路径不变性、真实返回收益排序、胜出参数回填、旧草稿保护；相关前端测试共 8 项通过，TypeScript、生产构建与新增模块 ESLint 通过。
