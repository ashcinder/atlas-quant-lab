# 私有策略：源码留在开发者一侧

2026-09-12，QuantJudge 分支。

## 结论与当前实现

推荐将平台与策略执行端分开。网站账号、订阅、交易记录和资产数据可以继续入库；策略源码、参数文件及签名私钥保留在开发者自己的电脑或服务器。仅把策略移到平台加密文件中，无法阻止平台管理员在解密执行时读取它。

本次新增 `private_runner` 模式，平台发布接口不接收源码或规则，只保存公开策略信息、公钥、加盐代码承诺与版本指纹。旧的 builtin/custom 策略和研究草稿仍按原方式存储；没有擅自迁移或删除历史内容，不能将它们视为私有执行。

本地工具执行开发者提供的 Python `decide(context)`，将目标仓位签名后发送到平台。每条信号绑定运行ID、发布版本ID、版本哈希、时间和一次性nonce。平台检查Ed25519签名、30秒时效、单调时间、去重、订阅运行状态、执行间隔和暂停/恢复边界。签名接口无需登录cookie，只能操作签名公钥对应版本的活动实例，且当前限定BTC-USDT平台模拟。

成交价格由平台重新获取实时买卖盘口，按已有账本计算费用、滑点、持仓及净值；不接收开发者上传的收益数字。信号处理失败不会自动重试成交。源码不发给平台，但交易信号会被平台观察，不能保证无法从长期交易行为推测部分策略。

## 当前证据不能被混淆

| 证据 | 能证明 | 当前状态 |
| --- | --- | --- |
| 信号签名 | 持有登记私钥的一方发出了该信号 | 本次实现并验收 |
| 平台模拟账本 | 平台按记录的模拟成交规则计算了费用和收益 | 已运行；不是交易所成交 |
| 交易所回执 | 交易所实际接受并成交的订单 | 此私有模式尚未接入exchange_test/live；此前普通策略适配器仍独立存在 |
| 策略ID与版本承诺上链 | 该版本承诺在某区块已登记 | 接口与钱包入口完成；Supervisor未连通，尚无真实上链回执 |
| ZKP/TEE执行证明 | 在特定信任边界内，运行的程序/私密策略与承诺及输入输出相符 | 此私有runner尚未实现，普通签名不能替代 |

因此，本次实现“源码不上传并能跑起来”，尚不能承诺“任意私有策略的执行与真实收益均被密码学保证”。本地工具校验代码文件哈希能发现正常使用中的代码变更，但开发者可修改自己的工具或另写签名程序；代码承诺也尚未覆盖导入依赖、解释器、外部配置和所有状态。需要ZKP或可信TEE执行协议才能消除这项信任。

建议生产方案：开发者控制密钥释放，先核验独立审计的TEE执行镜像和临时公钥，再向该执行环境加密发送策略；行情与交易所成交回执直接进入经过证明的执行环境，收益报告绑定代码承诺、输入摘要、现金流、费用和结果。平台管理员不能控制白名单/密钥释放策略。ZKP适合随后对受限计算生成独立证明；单纯在页面调用TEE校验接口不足以建立这条路径。AWS提供[基于证明和PCR的KMS解密机制](https://docs.aws.amazon.com/enclaves/latest/user/connect-enclave-kms.html)，但本项目本次未部署这类硬件及密钥基础设施。

## 使用流程

在策略开发者自己的机器安装脚本需要的Python、httpx和cryptography。项目环境可使用 `backend/.venv/bin/python`。

```bash
backend/.venv/bin/python scripts/private-strategy-runner.py init \
  --strategy /自己的目录/strategy.py \
  --directory /自己的私有目录 \
  --name '我的私有策略'
```

生成 `release.public.json`（公开登记文件）、`runner.key`（私钥）、`local.json`（源码路径及私有盐）。后两者不要上传；文件权限0600。仅选择 `release.public.json`：策略市场 → 可运行策略 → 登记不上传源码的私有策略。登记后自动订阅。

策略交易创建运行，选择该版本，点击“启动并等待本地信号”。展开详情中的“本地执行连接配置”，将JSON保存为开发者本地的 `run.json`，然后运行：

```bash
backend/.venv/bin/python scripts/private-strategy-runner.py run \
  --directory /自己的私有目录 --config /自己的目录/run.json \
  --steps 12 --interval 12
```

示例策略位于 `strategy/examples/private-local/strategy.py`，按步骤交替10%仓位和空仓，仅做功能联调。每个运行实例独立执行；没有提供自动分发到所有订阅者的服务。脚本结束后不自动清仓或暂停实例，需在页面核对持仓并暂停。平台没有新信号时不会自动运行该私有策略。平台需要持续在线；远程连接必须用HTTPS。

## Supervisor存证

在“我的策略”打开对应版本“策略版本上链佐证”。钱包切换链1051，点击“钱包签名上链”；钱包展示网络费用并由用户签名。零金额交易发送至自己的钱包地址，input内记录域、chain ID、策略ID、版本ID、版本哈希、发布者摘要，以及私有模式的公钥/代码承诺，不包含源码。

后端通过Supervisor RPC校验chain ID、交易哈希、发送/接收地址、零金额、完整input、回执成功状态与当前区块哈希。页面区分待签名、待确认、已核验、失败与链不可达。已核验是上次查询结果；再次核验可检测区块重组。存证不等于链上ZKP verifier。

当前本机 `127.0.0.1:42515` 无服务监听，无法完成真实上链；没有伪造确认或用另一条链代替Supervisor。需提供可用的链1051 RPC，以及用户钱包签名和网络费用。平台不接收钱包私钥。
